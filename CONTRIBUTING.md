# Contributing

Thank you for taking an interest in Trindle Scan. It is appreciated.

The way this project is set up, the code is written and kept in one place, so code changes from outside cannot be taken. That has nothing to do with the quality of anyone's work. It works best when we hear what went wrong and fix it ourselves.

So the most useful thing you can send is a description:

- **Something broken?** Report bugs and crashes on the [Buildmorphic bug report page](https://trindle.buildmorphic.com/report); questions and chat are on the [Buildmorphic community](https://trindle.buildmorphic.com). Say what you did, what you expected, and what happened instead. The version, your scanner's make and model, and whether it is a network or USB scanner help a great deal. A picture of the window is welcome.
- **An idea?** Say what you were trying to do and where Trindle Scan got in the way. You do not need to suggest the fix.
- **A security problem?** Please use private reporting rather than a public issue. [SECURITY.md](SECURITY.md) explains how.

Trindle Scan is under the GNU General Public License, so you are always free to fork it and take it in your own direction.
